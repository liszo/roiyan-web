# متن ویزارد تشخیص — نسخه پیش‌نویس

> **منبع:** `docs/20_WEBSITE WIZARD SPEC.md` §1–§4 و §6–§7 · لحن: `DESIGN.md` §2 · قیمت و سقف‌ها: `docs/11_PRICING AND OUTCOME MODEL.md` §6.
> **وضعیت:** پیش‌نویس برای بازبینی. هر جا قانون یا گزینه در مشخصات (spec) روشن نبود با `[TODO]` علامت خورده است.

## راهنمای خواندن

- **مسیر کسب‌وکار کوچک (SB):** گروه G1 (کسب‌وکار کوچک)، G3 (در حال راه‌اندازی)، G4 (کار برای خود). **مسیر سازمان (Org):** گروه G2.
- **متغیرها:** `{biz}` = نام کسب‌وکار در جمله (جدول «نقش‌ها» در بخش ۱۲)، `{n}` = عدد، `{month}` = ماه شمسی جاری. اعداد همیشه با رقم فارسی نمایش داده می‌شوند و به API با رقم لاتین فرستاده می‌شوند.
- **لحن:** «شما»، ساده و مستقیم. بدون «بهترین» و «تضمینی». بدون فوریت ساختگی. به‌جای «لید» می‌نویسیم «سرنخ».
- **قانون گزینه‌ها:** هر گزینه حداکثر ۵ کلمه است؛ توضیح یک‌خطی (hint) اختیاری است. نقش، فقط جمله‌بندی و گزینهٔ پیش‌انتخاب‌شده را عوض می‌کند، نه معنای گزینه‌ها و نه قیمت را.

## ۱ · متن‌های مشترک همهٔ مرحله‌ها

| محل | متن |
|---|---|
| نوار پیشرفت | مرحله {n} از {total} |
| دکمهٔ شروع ویزارد (هر جا از بیرون به ویزارد می‌رسیم) | شروع تشخیص رایگان |
| دکمهٔ بعدی (بین مرحله‌ها) | ادامه |
| دکمهٔ قبلی | بازگشت |
| دکمهٔ آخرین سؤال (پیش از شمارهٔ موبایل) | ساخت پلن من |
| محدودیت چندانتخابی (۲ مورد) | تا ۲ مورد |
| محدودیت چندانتخابی (۳ مورد) | تا ۳ مورد |
| وقتی سقف پر شد | به سقف رسیده‌اید. برای انتخاب مورد دیگر، یکی را بردارید. |
| وقتی هیچ گزینه‌ای انتخاب نشده | یک گزینه را انتخاب کنید. |
| ذخیرهٔ ناموفق پاسخ | پاسخ شما ذخیره نشد. دوباره تلاش کنید. |

- **شمارش مرحله‌ها بر اساس مسیر:** `{total}` = ۹ برای G1 و G2؛ ۸ برای G3 و G4، چون این دو مرحلهٔ نقش را رد می‌کنند و نقش R-OWN خودکار ثبت می‌شود. `{n}` پشت‌سرهم شمرده می‌شود؛ مثلاً سؤال «حوزهٔ فعالیت» برای G3 و G4 «مرحله ۲ از ۸» است. شمارهٔ بخش‌های این فایل همان شمارهٔ مشخصات (spec) است، نه عددی که روی صفحه نشان داده می‌شود.
- «ادامه» دکمهٔ حرکت بین مرحله‌هاست. دکمهٔ اصلی ورود به ویزارد در همهٔ سایت فقط «شروع تشخیص رایگان» است.

## ۳ · مرحلهٔ ۲ — نقش شما

- گروه‌های G3 («در حال راه‌اندازی») و G4 («برای خودم کار می‌کنم») این مرحله را نمی‌بینند؛ نقش R-OWN خودکار ثبت می‌شود. شمارش مرحله‌ها برای این دو گروه یکی کمتر است (بخش ۱).

### گروه G1 — کسب‌وکار کوچک

**سؤال:** نقش شما در این کسب‌وکار چیست؟

| کد | گزینه |
|---|---|
| R-OWN | صاحب کسب‌وکار هستم |
| R-STF | برای صاحب کسب‌وکار کار می‌کنم |
| R-PRT | همسر یا شریک صاحب کسب‌وکار هستم |

### گروه G3 و G4

- این مرحله نمایش داده نمی‌شود. نقش R-OWN خودکار ثبت می‌شود و جمله‌بندی مخصوص G3 («راه‌اندازی»، «بنیان‌گذار») از گروه می‌آید، نه از انتخاب کاربر.

### گروه G2 — سازمان

**سؤال:** نقش شما در سازمان چیست؟

| کد | گزینه |
|---|---|
| R-CEO | مالک یا مدیرعامل |
| R-OPS | مدیر عملیات |
| R-SAL | مدیر فروش یا بازاریابی |
| R-HR | مدیر منابع انسانی |
| R-IT | مدیر فناوری یا دیجیتال |
| R-FIN | مدیر مالی |

- گزینهٔ «سایر» وجود ندارد (spec §2).
- راهنما: «نقش شما فقط جمله‌بندی و ترتیب سؤال‌ها را تغییر می‌دهد. قیمت برای همهٔ همکاران شما یکی است.»

`{role_order_note}` = «مشکل‌هایی که برای نقش شما رایج‌ترند، اول آمده‌اند.»

## ۷ · کارت بینش (بین مرحلهٔ ۵ و ۶)

- یک جمله از پاسخ‌های قبلی. بدون دکمه. پس‌زمینهٔ خنثی (DESIGN.md §7).
- الگوهای زیر فقط پاسخ‌های خود کاربر را بازگو می‌کنند و ادعای آماری نمی‌سازند.

| مسیر | الگو |
|---|---|
| SB | شما «{problem_1}» را بزرگ‌ترین مشکل {biz} دانستید. چند سؤال کوتاه مانده تا پلن را بر همین پایه بسازیم. |
| Org | «{problem_1}» مهم‌ترین موضوع شما در {biz} است. چند سؤال کوتاه دیگر برای ساخت پلن لازم است. |
| G3 | شروع کار با «{problem_1}» سخت شده. چند سؤال دیگر مانده تا اولین مسیرها را بسازیم. |

- **نمونهٔ spec:** «کسب‌وکارهایی مثل شما معمولاً بیشترین مشتری را در پیگیری از دست می‌دهند.» — [TODO] این جمله ادعاست. طبق DESIGN.md §2 باید عدد یا منبع واقعی کنارش باشد؛ تا آن موقع در نسخهٔ اجرایی استفاده نشود. نسخهٔ Org («سازمان‌هایی مثل شما معمولاً…») هم همین وضعیت را دارد.

**پس‌زمینه:** پیش‌نمایش محو (blur) از امتیاز؛ هیچ عددی خوانا نیست.

### G1 · G3 · G4

- **عنوان:** پلن شما آماده است
- **توضیح:** برای دیدن امتیاز و پلن، نام و شمارهٔ موبایل‌تان را وارد کنید.
- فیلدها: **نام** · **شمارهٔ موبایل** (جای‌نما: ۰۹۱۲۳۴۵۶۷۸۹)

### G2

- همان‌ها، با فیلد **نام شرکت یا سازمان**.
- **[SPRINT-2]** فیلد اختیاری: «شمارهٔ کسی که همراه شما تصمیم می‌گیرد» — راهنما: «اختیاری است. بعداً هم می‌توانید او را دعوت کنید.»

### چرا شماره را می‌خواهیم (زیر فیلد، همهٔ گروه‌ها)

> شمارهٔ شما برای تأیید اینکه خودتان هستید و نگه‌داشتن پلن لازم است تا بعداً به آن برگردید. همکار ما برای توضیح پلن با شما تماس می‌گیرد و لینک پلن را پیامک می‌کنیم.
> [حریم خصوصی](/harim)

### دکمه‌ها و مرحلهٔ کد

| محل | متن |
|---|---|
| دکمهٔ ارسال کد | ارسال کد تأیید |
| عنوان مرحلهٔ کد | کد تأیید را وارد کنید |
| توضیح | کد به شمارهٔ {phone} پیامک شد. |
| فیلد کد | کد تأیید (`inputmode="numeric"`، `autocomplete="one-time-code"`) |
| دکمهٔ تأیید | تأیید و دیدن پلن |
| ارسال دوباره | ارسال دوباره کد تا {seconds} ثانیه دیگر (شمارش از ۱۲۰) / پس از پایان شمارش: ارسال دوباره کد |
| شمارهٔ اشتباه | ویرایش شماره |

- مدت انتظار برای ارسال دوباره ۱۲۰ ثانیه است و با رقم فارسی نمایش داده می‌شود.
- سقف OTP (۳ بار برای هر شماره در ساعت، ۱۰ برای هر IP) را API اعمال می‌کند و پیام فارسی خودش را می‌دهد.
